# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on
[github.com/rejithr9/secure-webapp-framework](https://github.com/rejithr9/secure-webapp-framework/security/advisories/new).

Include what you found, how to reproduce it, and the version affected. You'll get an answer within
7 days. Fixes are released as a new version with a security advisory.
